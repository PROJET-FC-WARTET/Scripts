# UTILITAIRES — Scripts d'aide au développement

Ce dossier contient les **scripts d'assistance** qui facilitent le travail quotidien des développeurs.

## Rôle
- Automatiser les tâches répétitives (installation, nettoyage, sauvegarde).
- Fournir des outils de diagnostic et de maintenance.
- Aider à la préparation de l'environnement de développement.

## Contenu attendu
- **`install.sh`** : Installation des dépendances du projet.
- **`backup.sh`** : Sauvegarde de la base de données ou des fichiers.
- **`clean.sh`** : Nettoyage des fichiers temporaires.
- **`check_env.sh`** : Vérification de l'environnement de développement.

## Règle
> Ces scripts sont destinés à être exécutés **en local** par les développeurs, pas en production.
