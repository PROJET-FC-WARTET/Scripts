# Scripts — Projet de classe 2026

Scripts d'automatisation, de déploiement et de maintenance pour le site de classe.

## 📂 Organisation du dépôt

| Dossier | Rôle |
| :--- | :--- |
| **`.github/`** | Configuration GitHub (CODEOWNERS, templates). |
| **`DEPLOIEMENT/`** | Scripts de mise en production et configuration des environnements. |
| **`SHARED/`** | Code réutilisable pour les scripts. |
| **`TESTS/`** | Tests de validation des scripts. |
| **`UTILITAIRES/`** | Scripts d'aide au développement. |

## 🚀 Pour commencer

1. Clonez ce dépôt avec GitHub Desktop.
2. Créez une branche (voir le guide de collaboration).
3. Choisissez une tâche dans le Project de l'organisation.
4. Suivez le guide `GUIDE.md` pour les conventions.
